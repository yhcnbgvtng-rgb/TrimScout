# Chevrolet / GMC / Toyota / Ram trim probe, 2026-10-27

Read-only profile of `trim` on box2 `dealer_inventory`, used to build `scrapers/lightsail-crawler/src/oemTrim.js` (the Chevrolet / GMC / Toyota / Ram sibling of `fordTrim.js`). Counts only, no row data, nothing written or restarted. The raw output (every model label, top 50 trims each) is `oem-probe-2026-10-27-raw.txt`.

## How it was run

- box2 (`ssh box2`, `~/.ssh/config` alias; `52.202.234.65` per `docs/BOXES.md`), `/opt/trimscout-deals`, the deals app's **`DB_READER_USER`** (read-only account), `SET SESSION TRANSACTION READ ONLY`, `SET STATEMENT max_statement_time=20` on every query. The reader password was read on the box by the script and never printed.
- One query per (make, model prefix), 12 in all: `WHERE make = ? AND model LIKE ? AND removed_at IS NULL GROUP BY model, trim`. `EXPLAIN` first: every one uses `idx_inv_facet_make_model_state_trim` (range, index-only; 23k to 228k rows examined). None hit the cap.
- Active = `removed_at IS NULL`. Models labelled several ways (`Silverado 2500 HD` / `2500HD` / `2500 HD`, `RAV4 Hybrid` / `Plug-in Hybrid` / `Prime`) are folded by `oemTrimGroup`.

## Judgment calls (please push back)

- **Silverado "Work Truck" -> `WT`** (1,351 rows already say `WT`, 903 say `Work Truck`).
- **Tacoma / RAV4 "TRD Off Road" -> `TRD Off-Road`**, Toyota's own spelling (3,324 + 2,574 Tacoma rows are split between the two).
- **Camry "Nightshade" -> `SE Nightshade`** (Nightshade is only sold on the SE; 607 + 142 + 193 rows).
- **Ram "Big Horn/Lone Star" is one official trim** (it is the name on the build sheet; 9,500+ rows), with the glued spellings `Big Hornlone Star` and `BIGHORN/LONESTAR` mapped to it.
- **Sport / Pro are add-on words** next to a real trim (`Laramie Sport Appearance`, `AT4 Carbon PRO`): dropped when another trim is in the same text.
- Not matched at all: `Trail Boss` alone (LT or Custom?), `1LT` / `2LT` (package levels), `Work`, `RAM` (the make), `Grade 4x4`. These stay as they are.
- Two trims in one string (`LT Z71`, `Rebel/Power Wagon`, `LE SE`) are left alone, as with Ford.
